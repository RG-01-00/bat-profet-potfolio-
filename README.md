# Roufaida Gheraibia — AI Engineering Portfolio

Personal portfolio featuring applied ML pipelines, computer vision systems, Arabic NLP, and interactive client-side inference demos.

## Tech Stack
- React 19 + TypeScript
- Tailwind CSS v4
- Three.js + Postprocessing
- OGL (WebGL)
- Motion

## Run Locally
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
